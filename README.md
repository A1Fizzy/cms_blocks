# Полка — личная библиотека CMS-блоков

**Основной вариант размещения: Google Apps Script.** Готовые файлы находятся в `apps-script/`. [Пошаговая публикация в вашем аккаунте](apps-script/README.md). Ниже описан альтернативный локальный Python-сервер.

Однопользовательский сервис для хранения HTML и CSS: направления, поиск, визуальные карточки, редактирование, копирование кода. При первом запуске создаются направления «Статьи», «Разводящие», «Продуктовые». Блоки добавляются пользователем.

## Запуск

Требуется Python 3.12+. Сторонних зависимостей нет.

```sh
cd /workspace/cms_blocks
python server.py
```

По умолчанию сервер слушает `127.0.0.1:8000`. Переменные `HOST`, `PORT`, `BLOCKS_DB` позволяют изменить адрес, порт и расположение базы. Для остановки — Ctrl+C.

Данные хранятся в `.data/blocks.sqlite3` (не добавляется в Git). Для резервного копирования остановите сервер и скопируйте этот файл. Для восстановления верните его перед запуском. Удаление направления удаляет все его блоки после подтверждения.

Сервис предназначен для личного локального использования. Авторизации нет: не публикуйте его в интернете без HTTPS и защиты доступа. Предпросмотр использует sandbox без JavaScript; изображения и шрифты по HTTPS могут обращаться к внешним ресурсам. Стили предпросмотра включают базовые отступы и могут отличаться от окружения вашей CMS. Код копируется без добавленных стилей предпросмотра.

## Проверки

```sh
python -m unittest discover -s tests -v
node --check static/app.js
```

Тесты проверяют HTTP API, сохранение в SQLite, изменение и удаление блоков, каскадное удаление, валидацию и запрет записи с чужого origin. Браузерные сценарии: создать направление, добавить блок с HTML/CSS, проверить предпросмотр, скопировать оба поля, обновить страницу, найти блок поиском и удалить его.
